[Описати межу спостереження лабораторної роботи: що спостерігає студент і що залишається поза межею. Підтвердити, що лабораторна робота не змінює канонічну колекцію знань і що ранжований кандидатний вихід є єдиним спостережуваним виходом операції інформаційного пошуку.]

## Вибір конфігурації розбивки на фрагменти та межі одиниці інформаційного пошуку

[Описати дві надані конфігурації розбивки на фрагменти (`sentence-pair-v1` і `fixed-72-v1`) і результати застосування кожної до канонічних записів знань `R-A` і `R-B`. Пояснити, чому конфігурація `sentence-pair-v1` зберігає разом ідентифікатор первинного запису, версію запису й точне місце підтвердного уривка, потрібні за підставою для судження про релевантність обох випадків для оцінювання. Навести ідентифікатори отриманих одиниць інформаційного пошуку й підтвердити, що кожна одиниця фіксує класифікацію `derived retrieval-side artifact; not a canonical knowledge collection member`.]

## Ембединги одиниць інформаційного пошуку та підготовка векторного індексу

[Описати створення сумісних ембедингів одиниць інформаційного пошуку: модель ембедингу, ревізію моделі, версію представлення, розмірність ембедингу та простір ембедингів. Назвати зафіксовані одиниці інформаційного пошуку та підтвердити метаданні прив’язки для кожної з них у маніфесті індексу. Описати результат перевірки прив’язок перед використанням для `required-course-seed-v1` (припустимий векторний індекс) і для `required-course-seed-v2` (застарілий векторний індекс). Пояснити, що векторний індекс є похідним станом для пошуку, а не членом канонічної колекції знань.]

## Виконання чотирьох конфігурацій інформаційного пошуку

[Описати вісім ранжованих кандидатних виходів (два випадки для оцінювання × чотири конфігурації інформаційного пошуку). Для кожного запису назвати конфігурацію інформаційного пошуку, випадок для оцінювання та спостережений ранжований кандидатний вихід (стабільний ідентифікатор пошуку й бал або порожній результат). Пояснити, чому порожній ранжований кандидатний вихід відрізняється від відмови виконання. Зазначити, що результати є спостереженнями для двох оголошених випадків і не є доказом загальної переваги будь-якого механізму інформаційного пошуку.]

## Судження про релевантність

[Назвати оголошену підставу для судження про релевантність. Для кожної поверненої одиниці інформаційного пошуку в кожному випадку для оцінювання навести ідентифікатор одиниці інформаційного пошуку, судження (`relevant` або `not relevant`) і обґрунтування — пряме застосування підстави для судження про релевантність до конкретної одиниці інформаційного пошуку. Підтвердити, що операція інформаційного пошуку жодного разу не отримувала очікуваного результату, призначеного лише для оцінювача, і що зафіксовані судження охоплюють точно ті одиниці інформаційного пошуку, які повернули порівнювані конфігурації.]

## Метрики інформаційного пошуку

[Навести таблицю з вісьмома записами метрик для окремих випадків (чотири конфігурації інформаційного пошуку × два випадки для оцінювання), кожен із явним чисельником і знаменником для `precision@1` і `recall@1`. Явно позначити записи `undefined` для `precision@1` і пояснити, чому `precision@1` є `undefined`, а не нулем, коли ранжований кандидатний вихід порожній. Навести агреговані метрики для кожної конфігурації інформаційного пошуку та пояснити, як правило агрегації обробляє порожній ранжований кандидатний вихід.]

## Операційні свідчення

[Навести виміряні значення п’яти пунктів операційних свідчень для кожної конфігурації інформаційного пошуку: вартість побудови або оновлення підготовленого індексу, затримка запиту, вартість запиту, споживання ресурсів і помилки виконання — кожен із власною межею вимірювання. Підтвердити, що жодне вимірювання не входить до чисельника або знаменника `precision@1` чи `recall@1`.]

## Обмежене рішення щодо конфігурації

[Зафіксувати обрану конфігурацію інформаційного пошуку та обґрунтування, аргументоване за зафіксованими метриками й виміряними операційними свідченнями. Навести межу рішення (обидва випадки для оцінювання, версія `course-seed-v1`, межа одиниці інформаційного пошуку `sentence-pair-v1`, оголошена підстава для судження про релевантність і `k = 1`) та межу повноважень (рішення не встановлює якість кандидатного визначення поняття, не встановлює результат повного робочого процесу користувача й не уповноважує зміни канонічної колекції знань).]
